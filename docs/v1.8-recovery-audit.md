# v1.8 recovery audit

Audited 2026-11-01 against the v1.7.0 baseline: `main` at `12a002b`.

## Scope and preservation

Before creating `feat/v1.8-recovery-reliability`, the pre-existing modified
configuration, untracked local launch helpers, and ignored model preview assets
were archived outside the repository. The archive is deliberately not tracked:
it contains machine-local configuration and its checksum was recorded locally.
No company SO-14 source tree was copied or modified.

The audit examined local refs, reflogs, stashes, worktrees, unreachable Git
objects, all remote heads/tags, GitHub pull-request heads, nearby project and
document directories, VS Code local history, shell-history references, and
candidate patch/bundle/archive files.

## Findings

| Question | Finding | Evidence | Confidence |
|---|---|---|---|
| Is there a newer reachable ArgazUI source revision? | No. `main` and `origin/main` both resolve to `12a002b`; the checkout's reflog starts with its clone. | Git refs, reflog, `git fsck` | High |
| Is a lost local commit recoverable? | No. There are no stashes, linked worktrees, dangling objects, other Argaz clones, matching bundles, patches, or archives. | Local recovery scan | High for this computer; unknown for another computer or unmounted backup |
| Is there an alternate remote UI branch? | No. The three remote feature branches do not contain an alternative UI implementation. | `ls-remote`, UI-path diffs | High |
| Was the remembered preview UI removed? | No. v1.7's UI still has model cards, small thumbnails, selected-model preview, and image enlargement. | `index.html`, `app.js`, `models.json`, live UI | High |
| Why were previews absent after the clean clone? | Preview images are intentionally ignored, so `argazui/static/models/` was empty. The registry and UI implementation were present. | `.gitignore`, model API, live UI | High |
| Is an undocumented newer feature set recoverable? | No supporting source was found. It must not be recreated from memory. | All sources above | High |

## Candidate comparison

The final UI-affecting commit on the reachable mainline is `cb853d8` (`ui:
redesign ArgazUI as an industrial engineering workstation`, 2026-08-12).
Later mainline commits leading to `12a002b` do not introduce a newer interface.
The release tags stop at v1.3.0; they are ancestors of `main`.

The open branch behind pull request #3 has a narrowly scoped improvement:
`f66dbcc` passes `wait_for_report=True` through the shutdown-only path so a
last run's report is not cut off when the server exits. It adds focused
regression coverage and deliberately leaves ordinary STOP non-blocking. The
change is suitable for review and reuse in v1.8, subject to the full suite and
flight evidence.

## Recovery decision

Recovery from this machine is not possible. v1.8 therefore starts from the
verified v1.7 source, retains evidence-backed preview support, and makes no
claim that unrecovered features ever existed. A branch, commit, fork, mounted
backup, or prior workstation can be audited later without invalidating this
conclusion.
